\begin{abstract}
The Cyclic Bandwidth Minimization Problem (CBMP) is a graph-layout optimization problem that assigns vertices to positions on a cycle while minimizing the maximum cyclic distance over all edges. This work presents an iterative SAT-based feasibility framework using Order Encoding for distance constraints, Commander Encoding for exactly-one constraints, and rotation/reflection symmetry breaking; a Reverse Cuthill--McKee (RCM) layout supplies an initial upper bound. The repository also contains implementations of Pairwise Encoding, OR-Tools CP-SAT, IBM CPLEX MIP, CPLEX CP Optimizer, and a Gurobi baseline, together with experiment and analysis scripts. The repository preserves a time-stamped exploratory results snapshot and separate historical experiment archives. The tracked snapshot is not presented as a clean, fully reproducible benchmark; quantitative report tables and figures retain their explicitly documented historical provenance.
\end{abstract}

\section{Method}

    \subsection{Label assignment constraint}
        Each vertex $u$ corresponds to $N$ label variables $X_u=\left\{x_u^1,x_u^2,\dots,x_u^N\right\}$, where $x_u^k$ is true if vertex $u$ is assigned label $k$. Given $N$ vertices and $N$ unique labels, a valid assignment is one where \textit{each label $k$ is assigned to Exactly One vertex}, which can be expressed as the conjunction of an At Most One (AMO) constraint and an At Least One (ALO) constraint upon the sets of variables corresponding to each label $k$. Specifically, let $X^k = \{x_1^k, x_2^k, \dots, x_N^k\}$ be the variables representing the assignment of label $k$ to each vertex. For each $k$, the constraint is encoded as $\text{AMO}(X^k) \wedge \text{ALO}(X^k)$.

        \subsubsection{At Least One (ALO)}
            \noindent A single clause can be used to express $\text{ALO}(X^k)$:
            \begin{equation}
                \text{ALO}(X^k) = \bigvee_{u=1}^{N} x_u^k.
            \end{equation}

        \subsubsection{At Most One (AMO)}
            \noindent This report discusses 2 ways to encode $\text{AMO}(X^k)$:
            \begin{itemize}
                \item \textbf{Pairwise:} explicitly encode that if one variable is true, every other variable must be false:
                
                \begin{equation}
                    \text{AMO}(X^k) = \bigwedge_{u=1}^{N-1}
                    \bigwedge_{v=u+1}^{N}
                    \left(x_u^k \rightarrow \neg x_v^k\right)
                \end{equation}

                Or in CNF:
                \begin{equation}
                    \text{AMO}(X^k) = \bigwedge_{u=1}^{N-1}
                    \bigwedge_{v=u+1}^{N}
                    \left(\neg x_u^k \vee \neg x_v^k\right)
                \end{equation}

                It uses no auxiliary variables but needs $\binom{N}{2} = O(N^2)$ binary clauses.

                \item \textbf{Product:} arrange the $N$ variables in a $p \times q$ grid ($pq \ge N$, typically $p \approx q \approx \lceil\sqrt{N}\rceil$) and introduce row variables $r_1,\dots,r_p$ and column variables $c_1,\dots,c_q$. The variable in cell $(a,b)$ implies both its row and its column:
                    \begin{equation}
                        x_{a,b} \rightarrow r_a, \qquad x_{a,b} \rightarrow c_b.
                    \end{equation}
                    Then $\text{AMO}(r_1,\dots,r_p)$ and $\text{AMO}(c_1,\dots,c_q)$ are enforced (recursively with the product encoding, or pairwise when small). Two true variables would have to differ in a row or a column, violating one of the two AMO constraints. This uses $O(\sqrt{N})$ auxiliary variables and $O(N)$ clauses, far fewer clauses than pairwise for large $N$.
            \end{itemize}


    \subsection{Label range constraint}
        Given a graph $G(V,E)$ with $|V|=N$ and a bandwidth upper bound $\text{UB}$, we consider an assignment $A$ valid if every edge satisfies a bandwidth constraint, namely, the distance between the labels of its vertices must be less than UB.
        
        Let $a(u)=i$ and $a(v)=j$. In CBMP, labels lie on a circle and the distance between two labels is:
        \begin{equation}
            d(i,j) = \min\bigl(|i-j|,\; N-|i-j|\bigr).
            \label{eq:cyclic_distance}
        \end{equation}
        An edge $(u,v)\in E$ satisfies the bandwidth constraint if $d(i,j) \le \text{UB}-1$ (equivalently, $d(i,j) < \text{UB}$). The general approach to encoding this constraint involves fixing one vertex's label and applying a \textbf{label range constraint} on the other vertex. Specifically, for each $i$, if $a(u)=i$, then $a(v) \in [i-\text{UB}+1,\, i+\text{UB}-1] \bmod N$.
        
        \vspace{1em}

        Note that since $d(i,j)$ is symmetric, applying these constraints in one direction ($u \to v$) is sufficient. 

        \paragraph{\textbf{Direct encoding.}}
            The direct encoding explicitly forbids every pair of labels that are too far apart. Specifically, for each edge $(u,v)\in E$ and all assignments $a(u)=i$ and $a(v)=j$:
            \begin{equation}
                \neg x_u^i \vee \neg x_v^j \qquad \forall \; 1 \le i,j \le N,\; \text{if} \; d(i,j) \geq \text{UB}.
            \end{equation}

            \vspace{1em}

            Note that this encoding additionally requires $\text{AMO}(X_u) \wedge \text{ALO}(X_u)$ clauses for every vertex $u$, to ensure that each vertex is assigned exactly one label.

        \paragraph{\textbf{Order encoding.}}
            The order encoding introduces $N+1$ auxiliary variables \textit{per vertex}: $G_u=\{g_u^1, g_u^2,\dots, g_u^N, g_u^{N+1}\}$, where $g_u^k$ is true if $a(u) \ge k$. The variable $g_v^k$ expresses a left bound $a(v) \geq k$, while its negation $\neg g_v^k$ expresses a right bound $a(v) < k$.
            
            For example, with $N=6$ and $a(u)=3$:
            \begin{center}
                \begin{tabular}{c|ccccccc}
                    label $k$ & 1                   & 2                   & 3                   & 4 & 5 & 6 & 7  \\ \hline
                    $x_u^k$   & F                   & F                   & \textit{\textbf{T}} & F & F & F & \_ \\
                    $g_u^k$   & \textit{\textbf{T}} & \textit{\textbf{T}} & \textit{\textbf{T}} & F & F & F & F  \\
                \end{tabular}
            \end{center}

            \noindent This encoding is composed of 2 components: the consistency clauses and the biconditional clauses.

            \noindent \textit{The consistency clauses:}
            \begin{equation}
                g_u^{k+1} \rightarrow g_u^{k} \qquad \forall \; u\in V,\; 1 \le k < N
            \end{equation}
            In combination with the constants $g_u^1 = \text{true}$ and $g_u^{N+1} = \text{false}$, these clauses enforce that if $a(u)=k$, then $G_u$ is a series of true variables starting from the constant $g_u^1$ up until $g_u^k$, followed by a series of false variables, bounded by $g_u^{N+1}$.

            \vspace{1em}

            \noindent \textit{The biconditional clauses:}
            \begin{equation}
                x_u^k \leftrightarrow (g_u^k \wedge \neg g_u^{k+1}) \qquad \forall \; u\in V,\; 1 \le k \le N
            \end{equation}
            These clauses enforce the relationship between the auxiliary order variables and the label variables.

            \vspace{1em}

            Note that, by the \textit{biconditional clauses}, $x_u^k$ is true exactly when $g_u^k$ is true \textit{and} $g_u^{k+1}$ is false, which only happens at the point where $G_u$ switches from true to false. Since the constants $g_u^1 = \text{true}$ and $g_u^{N+1} = \text{false}$ guarantee that a switch exists at some point between $k=1$ and $k=N$, and the \textit{consistency clauses} guarantee that there is only one switch, it follows that exactly one $x_u^k$ is true for each vertex $u$. Therefore, the order encoding also ensures that every vertex is assigned exactly one label as a side effect.

            \vspace{1em}

            With this encoding, for each edge $(u,v)\in E$ and each label $i$ of $u$, and depending on whether the range of valid labels for $v$ wraps around the circle, the label range constraint can be written as follows:
            \begin{align}
                \intertext{\hspace*{\parindent}no wrap $(\text{UB} \le i \le N-\text{UB}+1)$:}
                x_u^i &\rightarrow g_v^{i-\text{UB}+1} \\
                x_u^i &\rightarrow \neg g_v^{i+\text{UB}} \\
                \intertext{\hspace*{\parindent}wraps left $(1 \leq i < \text{UB})$:}
                x_u^i &\rightarrow (\neg g_v^{i+\text{UB}} \vee g_v^{N+i-\text{UB}+1}) \\
                \intertext{\hspace*{\parindent}wraps right $(N-\text{UB}+1 < i \leq N)$:}
                x_u^i &\rightarrow (\neg g_v^{i+\text{UB}-N} \vee g_v^{i-\text{UB}+1})
            \end{align}

            In the wrapping cases the allowed sets are a union of two intervals, $[1,\,i+\text{UB}-1] \cup [N+i-\text{UB}+1,\,N]$ when wrapping left, and $[1,\,i+\text{UB}-N-1] \cup [i-\text{UB}+1,\,N]$ when wrapping right. The two wrapping cases cannot occur simultaneously when the upper bound is correctly initialized as $\text{UB} \le \left\lfloor \frac{N}{2} \right\rfloor$.

        \paragraph{\textbf{Clause counts.}}
            Assuming $\text{UB} \le \left\lfloor \frac{N}{2} \right\rfloor$, the allowed label range of $v$ contains $2\,\text{UB}-1$ labels, so for each of the $N$ potential labels $i\in [1,N]$ of $u$: the direct encoding forbids $N-(2\,\text{UB}-1)$ labels of $v$, therefore $N(N-2\,\text{UB}+1)$ clauses are required \textit{per edge}. Additionally, the direct encoding needs roughly $2N$ $\text{AMO}$ clauses (product encoding) and 1 $\text{ALO}$ clause \textit{per vertex} to ensure that each vertex is assigned exactly one label, so the total number of clauses required is about $|E|\cdot N(N-2\,\text{UB}+1) + N(2N+1)$. The order encoding takes roughly 2 clauses for each of the $N-2\,\text{UB}+2$ potential labels $i\in [\text{UB},N-\text{UB}+1]$ of $u$ that don't cause the valid label range of $v$ to wrap, plus 1 clause for each of the $2(\text{UB}-1)$ wrapping cases, therefore about $2N-2\,\text{UB}+2$ clauses are required \textit{per edge}. In addition, for each vertex $u$, it needs: roughly $N$ consistency clauses, $3N$ biconditional clauses, and 2 clauses for the constants $g_u^1$ and $g_u^{N+1}$, which brings the total to around $|E|\cdot (2N-2\,\text{UB}+2) + N(4N+2)$ clauses. This gives $O(|E|\cdot N^2)$ clauses for the direct encoding and $O(|E|\cdot N + N^2)$ for the order encoding.

    \subsection{Finding the minimum bandwidth using Incremental SAT}
        In order to find the minimum bandwidth of a graph, we repeatedly try to find assignments that satisfiy a shrinking upper bound until a valid assignment no longer exists. In SAT solving terms, we try to solve a sequence of formulas, each enforcing a smaller $\text{UB}$. Each satisfiable result updates $\text{UB}$ to the bandwidth of the assignment found, and the first UNSAT result proves that the current $\text{UB}$ is already minimal.

        \vspace{1em}

        \noindent Due to the monotonicity of the order encoding:
        \begin{align}
            &g_u^{k+1} \rightarrow g_u^k \\
            &\neg g_u^k \rightarrow \neg g_u^{k+1}
        \end{align}
        
        \noindent the clauses for a smaller $\text{UB}$ imply those for previous, larger $\text{UB}$s:
        \begin{align}
            &g_v^{k-\text{UB}+1} \rightarrow g_v^{k-\text{UB}} \\
            &\neg g_v^{k+\text{UB}} \rightarrow \neg g_v^{k+\text{UB}+1}
        \end{align}
        
        Therefore, each subsequent formula can be obtained by appending new clauses, which enforce a smaller $\text{UB}$, to the previous formula. As each new formula is just an extension of a formula that the solver has already solved, this enables the same solver instance to be reused to solve them, rather than re-initialized. This technique is known as Incremental SAT, and it allows the solver to retain its internal heuristics and learned clauses across formulas, which can potentially reduce solve times.

        \paragraph{\textbf{Initial upper bound.}}
            The search proceeds downwards from an initial upper bound, which is the bandwidth computed from a heuristic assignment (e.g.\ Cuthill-McKee).

        \begin{algorithm}[H]
            \caption{Pseudocode of Incremental SAT for the cyclic bandwidth problem}
            \begin{algorithmic}[1]
                \State \textbf{Input}: Undirected graph $G(V,E)$ with $|V|=N$, time limit: $T_{\max}$
                \State \textbf{Output}: The best assignment $A$, and its resulting bandwidth $\text{UB}$
                \Statex
                \State $A \gets \textsc{InitialAssignment}(G)$ \Comment{heuristic assignment, e.g.\ Cuthill-McKee}
                \State $\text{UB} \gets \textsc{Bandwidth}(A)$
                \State $\text{clauses} \gets \textsc{InitialClauses}()$ \Comment{label assignment constraints, order encoding consistency constraints,...}
                \Statex
                \While{$\textsc{TimeElapsed}() < T_{\max}$}
                    \ForAll{$(u,v) \in E$}
                        \For{$i = 1$ \textbf{to} $N$}
                            \State $\text{clauses}$.append( $[a(u)=i] \rightarrow [\min(|a(u)-a(v)|,\, N-|a(u)-a(v)|) \le \text{UB}-1]$ )
                        \EndFor
                    \EndFor
                    \Statex
                    \State $result, model \gets \textsc{Solve}(\text{clauses}, T_{\max}-\textsc{TimeElapsed}())$
                    \If{$result$ is UNSAT \textbf{or} $\textsc{TimeElapsed}() > T_{\max}$}
                        \State \textbf{break} \Comment{UNSAT: $\text{UB}$ is minimal; timeout: best bound found}
                    \EndIf
                    \Statex
                    \State $A \gets \textsc{ExtractAssignment}(model)$
                    \State $\text{UB} \gets \textsc{Bandwidth}(A)$ \Comment{may be smaller than the enforced $\text{UB}-1$}
                \EndWhile
                \Statex
                \State \textbf{return} $A$, $\text{UB}$
            \end{algorithmic}
        \end{algorithm}

\subsection{Bijective Assignment: Commander Encoding}
A valid layout requires that every label $i \in \{0, \dots, N-1\}$ is assigned to exactly one vertex $u \in V$. That is, for each column $i$, the variable set $X^i = \{x_0^i, x_1^i, \dots, x_{N-1}^i\}$ must satisfy $\text{EO}(X^i) = \text{ALO}(X^i) \land \text{AMO}(X^i)$.

Rather than using a quadratic pairwise encoding ($\mathcal{O}(N^2)$ binary clauses per label) or a 2D product encoding, our implementation employs \textbf{Commander Encoding} \citep{klieber2007efficient} with group width $W = 3$ (as implemented in \texttt{alo\_amo\_eo\_encodings.py}).

The algorithm partitions the $N$ variables into $\lceil N/W \rceil$ disjoint groups of size at most 3:
\begin{enumerate}
    \item \textbf{Intra-group AMO}: For each group $\{x_{g,1}, x_{g,2}, x_{g,3}\}$, standard pairwise mutex clauses are added:
    \begin{equation}
        (\neg x_{g,1} \lor \neg x_{g,2}) \land (\neg x_{g,2} \lor \neg x_{g,3}) \land (\neg x_{g,3} \lor \neg x_{g,1}).
    \end{equation}
    \item \textbf{Commander Variables}: For each group $g$, an auxiliary commander variable $c_g$ is introduced to represent whether any variable in group $g$ is true:
    \begin{align}
        x_{g,j} &\implies c_g \iff (\neg x_{g,j} \lor c_g) \quad \forall j, \\
        c_g &\implies \bigvee_{j} x_{g,j} \iff \left(\neg c_g \lor \bigvee_{j} x_{g,j}\right).
    \end{align}
    \item \textbf{Recursive Inter-group AMO}: The commander variables $\{c_1, c_2, \dots\}$ are recursively partitioned until a single top-level group remains.
    \item \textbf{Top-level ALO}: A single ALO clause is posted over the final top-level commander variables:
    \begin{equation}
        \bigvee_{k} c_{\text{top}, k}.
    \end{equation}
    Because the implication $c_g \implies \bigvee_j x_{g,j}$ propagates downwards through all recursion levels, satisfying the top-level ALO guarantees that at least one original variable is true. Together with the hierarchical AMO constraints, this guarantees that exactly one variable in $X^i$ is true.
\end{enumerate}
Commander encoding requires $\mathcal{O}(N)$ auxiliary variables and $\mathcal{O}(N)$ clauses per label, maintaining linear footprint per label without the routing overhead of deep sorting networks.

\subsection{Symmetry Breaking Constraints}

\paragraph{Rotation Symmetry Breaking:}
To break the $N$-fold circular rotation symmetry, we fix an arbitrary anchor vertex (chosen as $v_0$) to label 0:
\begin{equation}
    f(v_0) = 0 \iff [x_0^0].
    \label{eq:sb_rotation}
\end{equation}
Since any valid layout can be rotated so that $v_0$ is at position 0 without altering the cyclic bandwidth, this unit clause eliminates $N - 1$ redundant rotations while preserving at least one optimal representative.

\paragraph{Reflection Symmetry Breaking:}
With $f(v_0) = 0$ fixed, the circle admits an isometric reflection $\sigma(k) = (N - k) \bmod N$, which leaves label 0 unchanged and reverses the orientation of all other vertices ($1 \le k \le N-1$).

For $N \ge 3$, vertices $v_1$ and $v_{N-1}$ are distinct. To break reflection symmetry, we enforce that $v_1$ is positioned before $v_{N-1}$ along the cycle:
\begin{equation}
    f(v_1) < f(v_{N-1}).
    \label{eq:sb_reflection_math}
\end{equation}
Because all vertex labels are distinct and $f(v_0) = 0$, both $f(v_1)$ and $f(v_{N-1})$ are strictly positive and distinct. In our order encoding, Eq.~(\ref{eq:sb_reflection_math}) is encoded by asserting that if $f(v_{N-1}) = i$, then $f(v_1) < i$, which is equivalent to $\neg g_1^i$:
\begin{equation}
    x_{N-1}^i \implies \neg g_1^i \iff (\neg x_{N-1}^i \lor \neg g_1^i) \quad \forall i \in \{0, \dots, N-1\}.
    \label{eq:sb_reflection_clauses}
\end{equation}
If $N < 3$, $v_1$ and $v_{N-1}$ coincide ($1 = 2 - 1$), which would lead to an unsatisfiable constraint $f(v_1) < f(v_1)$; our implementation guards against this by checking $N \ge 3$.

\subsection{Heuristic Initial Upper Bound}
To minimize the number of iterations required to reach the optimum, we seed the search with an initial upper bound obtained from the \textbf{Reverse Cuthill--McKee (RCM)} algorithm \citep{cuthill1969rcm}. RCM constructs a breadth-first search layout starting from a pseudo-peripheral vertex, which notoriously produces low envelope and bandwidth on sparse physical graphs.

The RCM layout is evaluated via Eq.~(\ref{eq:cyclic_distance}) to obtain an initial bandwidth $\text{UB}_{\text{rcm}}$. If the heuristic permutation is valid, we set $\text{UB} = \text{UB}_{\text{rcm}}$; otherwise, the search defaults to the trivial bound $\text{UB} = \lfloor N/2 \rfloor + 1$.

\section{Experiments}

\subsection{Experimental Setup}

The current evaluation uses eight benchmark instances from the repository's MatrixMarket dataset collection: \texttt{14\_bus} ($N=14$), \texttt{30\_bus} ($N=30$), and connected induced subgraphs \texttt{494\_bus\_n40}, \texttt{662\_bus\_n40}, \texttt{494\_bus\_n60}, \texttt{662\_bus\_n60}, \texttt{494\_bus\_n80}, and \texttt{662\_bus\_n80}. The SAT experiments use PySAT with CaDiCaL~195. The Order and Pairwise distance encodings are run in \texttt{incremental} mode with the same symmetry-breaking constraints, RCM initial upper-bound heuristic, and Commander exactly-one strategy. The medium-instance solver comparison uses Order Encoding and the same SAT configuration for CaDiCaL~195, Glucose~4, MapleChrono, MiniSat~2.2, and Lingeling. The exact-solver comparison includes CP-SAT, CPLEX MIP, CPLEX CP Optimizer, and Gurobi. The time limit is 600 seconds.

The current snapshot contains 44 unique JSONL records: 24 \texttt{OPTIMAL}, 12 \texttt{TIMEOUT}, 4 \texttt{UNAVAILABLE}, 3 \texttt{SIZE\_LIMIT}, and 1 \texttt{FEASIBLE}. Each dataset/configuration is represented by one run in this snapshot. Reported runtimes are per-run measurements, not repeated-run averages or statistical estimates.

\subsection{Discussion and Limitations}

The current results support three conclusions. First, both Pairwise and Order Encoding are implemented and prove the same optimum on the four paired small instances. Second, the exact-solver results demonstrate agreement among SAT, CP-SAT, and the completed CPLEX runs where optimality is proved, while also exposing practical solver availability and model-size constraints. Third, the medium solver batch shows that the ability to find an incumbent does not imply that a solver proves optimality within the time limit.

The current result snapshot does not contain runs on the full \texttt{494\_bus} and \texttt{662\_bus} matrices, so large-matrix scalability is not yet demonstrated by these results. It also contains only one run per dataset/configuration; repeated trials and statistical summaries are not available. No current ablation, randomized-label family, or phase-decomposition records are included, so no claims about those experiments are made here.

\section{Conclusion}

This repository implements CBMP solving with both Pairwise and Order SAT encodings, incremental SAT solving, Commander exactly-one constraints, and rotation/reflection symmetry breaking. The current snapshot records successful optimality proofs from both SAT encodings and CP-SAT on four small instances, together with a five-solver SAT comparison on four medium subgraphs. CPLEX MIP is limited by the available edition on three instances; CPLEX CP Optimizer has one feasible-but-unproven result; and Gurobi is unavailable in the recorded environment.

The full benchmark matrices are present in the repository, but the current snapshot does not yet include experiments on the $N=494$ and $N=662$ graphs. Future work should prioritize those large-instance runs and repeated trials before drawing stronger scalability or statistical conclusions.
